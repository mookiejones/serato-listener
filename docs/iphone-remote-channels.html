How a subscription is sent. The strings in the binary have no leading slash. The listener sends /Register/ plus the path, the same way it already sends /Register/Status/Deck/Playhead. Until one of the open addresses is registered, Serato does not push it, so it cannot arrive as an ex event.

ACI is a separate family. /Status/ACI/ and /Control/ACI/ take an id. Those ids are packed in userio_resources.bin, not stored as OSC paths.

Unsubscribe and control. /Deregister/ is the matching unsubscribe prefix. The binary has no fixed /Control/Deck/… strings. This process does not send /Control/ messages.
